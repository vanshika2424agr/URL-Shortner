# 🔗 URL Shortener Service (Node.js + Express + MongoDB)

A simple and efficient **URL Shortener backend API** built using **Node.js, Express, and MongoDB Atlas**.  
It converts long URLs into short, shareable links and redirects users to the original URL when accessed.

---

## 🚀 Features

- 🔗 Shorten long URLs into unique short codes  
- 🔄 Redirect short URLs to original URLs  
- 🗄️ MongoDB Atlas database integration  
- 🌐 RESTful API architecture  
- ⚙️ Environment variable support using `.env`  
- 📦 Clean and modular project structure  

---

## 🛠️ Tech Stack

- Node.js  
- Express.js  
- MongoDB Atlas  
- Mongoose  
- dotenv
